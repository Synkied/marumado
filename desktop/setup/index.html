Marumado

Marumado runs on this computer, in Docker, started and stopped by this app. You need Docker installed and running; the app does the rest, and updates Marumado when the app is updated.

Folders that hold your projects

    Each folder inside one is a project. Marumado only reads them. None is fine too, for a machine without projects.

    Which Marumado should this app open? The one on this machine answers at http://127.0.0.1:7878; for another machine, use its address on your network or an SSH tunnel to it.

    make access-token prints it on the machine Marumado runs on.
